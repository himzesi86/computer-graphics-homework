# 作业 3：欧拉操作

用边界表示（B-Rep）和五个欧拉算子构造一个带方形通孔的立方体，再用 OpenGL 以线框显示，支持旋转、平移和缩放。

本仓库是黄锦中 HW3 的源码，文件直接放在仓库根目录。Visual Studio 工程、GLFW、GLAD 和编译产物没有放进仓库。

源文件使用 GBK 编码。

## 技术栈与关键词

- 技术栈：C++、OpenGL、GLFW、GLAD、Visual Studio、B-Rep、半边结构
- 关键词：计算机图形学、欧拉操作、欧拉算子、边界表示、mvfs、mev、mef、kemr、kfmrh、实体建模、通孔、线框渲染、作业3

## 欧拉算子

| 算子 | 作用 |
| --- | --- |
| `mvfs` | 由一个点生成体、面、环和顶点 |
| `mev` | 生成一条边和一个新顶点 |
| `mef` | 连接两个顶点，分裂出新面和新环 |
| `kemr` | 删除一条边，把一个环拆成两个环 |
| `kfmrh` | 合并两个面，把一个环变成另一个面的内环，用来打通孔 |

拓扑结构定义在 `SolidModel.h`：`Body`、`Face`、`Loop`、`Edge`、`Halfedge`、`Vertex`。半边成对保存，并带前驱、后继和所在环。

## 建模过程

`main.cpp` 里的构造顺序：

1. `mvfs` 生成原点上的第一个顶点。
2. 用 `mev` 拉出底面和顶面的八个顶点。
3. 用 `mef` 封出底面、顶面和四个侧面。
4. 在底面和顶面内部分别拉出方形孔的边界，并用 `mef` 生成内环。
5. `kfmrh` 把内环并进对应的外环，形成贯通的方孔。
6. `cleanup_extra_edges` 去掉构造过程中留下的桥边。

建完后把实体的边转成线段，交给 `Rendering.h` 里的 OpenGL 线框渲染。

## 操作

- 鼠标左键拖动：旋转
- 鼠标右键拖动：平移
- 鼠标中键拖动：缩放
- 键盘 `R`：恢复初始视图

## 构建

源文件使用 Visual Studio 编译。需要自行安装 GLFW 和 GLAD，并把它们的头文件、链接库加入包含路径和库路径。仓库里没有解决方案文件。
