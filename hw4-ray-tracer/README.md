# 作业 4：光线跟踪

一个从零写的 Whitted 风格光线跟踪器。从相机向每个像素发射光线，与场景求交后计算局部光照，并沿反射、折射方向递归，最后用 OpenCV 写出图片。

源码在 `HW4自己/HW4`，工程文件是 `HW4自己/HW.sln`。`HW4自己/HW4` 下的两张 jpg 是已经渲染好的结果。

源文件使用 GBK 编码。

## 技术栈与关键词

- 技术栈：C++、Eigen、OpenCV、Visual Studio、Whitted 光线跟踪
- 关键词：计算机图形学、光线跟踪、Ray Tracing、路径递归、反射、折射、Phong、阴影光线、球体、AABB、圆柱、圆环、Torus、作业4

## 场景

`main.cpp` 的 `setup_scene` 搭了一个封闭房间，里面有：

- 一个透明玻璃球
- 一个绿色漫反射球
- 一个蓝色立方体
- 两个圆柱（红色、黄色）和一个紫色圆环
- 三盏点光源，另加恒定环境光

默认渲染 800×600，递归深度 5。输出文件名在 `main.cpp` 末尾的 `imwrite` 处。

## 实现

几何体都继承 `Object`，各自实现 `intersect`：

| 类型 | 求交 |
| --- | --- |
| `Sphere` | 光线与球的二次方程 |
| `Cube` | 轴对齐包围盒的 slab 方法 |
| `plane` | 光线与无限平面 |
| `Cylinder` | 侧面二次方程，再裁到有限高度，并检测两个底面 |
| `Torus` | 光线与圆环的四次方程 |

`trace_ray` 取最近交点，用环境光、漫反射和 Phong 高光着色，并用阴影光线判断是否被挡住。材质里的 `reflectivity` 和 `transparency` 分别产生反射光线和折射光线；折射使用材质上的折射率。深度耗尽或没有命中时返回背景色。

## 构建与运行

Eigen 头文件在 `HW4自己/include/Eigen`。OpenCV 4.12 的库和 DLL 没有放进仓库，需要按工程里的 `..\include`、`..\lib` 和解决方案下的 `bin` 自行放置。用 Visual Studio 打开 `HW4自己/HW.sln` 后直接运行，程序会渲染整张图并保存，没有交互界面。场景物体、灯光、分辨率和递归深度都改 `HW4自己/HW4/main.cpp`。
