# 作业 2：栅格化与 Z-Buffer

在作业 1 的变换和线框绘制之上，补上三角形实心填充和深度测试。多个三角形重叠时，只保留离相机更近的片段。

源码在 `HW2/HW2`，工程文件是 `HW2/HW.sln`。`include` 下的 Eigen 是第三方库。

## 技术栈与关键词

- 技术栈：C++、Eigen、OpenCV、Visual Studio、软件光栅化
- 关键词：计算机图形学、栅格化、Z-Buffer、深度缓冲、重心坐标、重心插值、三角形填充、深度测试、作业2

## 做了什么

- 保留作业 1 的模型、视图、透视投影和视口变换，窗口仍是 700×700。
- `rasterize_triangle`：求三角形的屏幕包围盒，逐像素用重心坐标判断是否在三角形内，再用三个顶点颜色做重心插值。
- 每个像素维护 `depth_buf`。新片段的深度更小（更近）才写入颜色缓冲，否则丢弃。
- 顶点除位置外增加颜色缓冲，`draw` 同时接收位置、索引和颜色。

场景里放了两个三角形，用来观察遮挡。默认相机在 `(0, 0, 5)`，按 `A` / `D` 以 10° 为步进绕 Z 轴旋转，`Esc` 退出。传入命令行参数时改为渲染一帧并保存图片。

## 构建

用 Visual Studio 打开 `HW2/HW.sln`。Eigen 头文件在 `HW2/include/Eigen`。OpenCV 4.12 的头文件、`opencv_world4120.lib` 和 DLL 没有放进仓库，需要按工程里的 `..\include`、`..\lib` 和解决方案下的 `bin` 自行放置。
