# 作业 1：旋转与投影

软件光栅化器的第一版。给定一个三角形，手写绕 Z 轴旋转、视图变换和透视投影，再用 Bresenham 画线画出线框，结果用 OpenCV 显示或保存成图片。

源码在 `202330450581+黄锦中+HW1`，工程文件是 `CGHW1.sln`。本仓库只包含源码，不包含 `HWd.exe`。

## 技术栈与关键词

- 技术栈：C++、Eigen、OpenCV、Visual Studio、软件光栅化
- 关键词：计算机图形学、旋转、透视投影、视图变换、模型矩阵、罗德里格斯公式、Rodrigues、Bresenham、线框、MVP、光栅化、作业1

## 做了什么

- `get_model_matrix`：绕 Z 轴旋转，角度制输入后转成弧度。
- `get_rotation`：提高项，用罗德里格斯公式绕任意过原点的轴旋转。
- `get_view_matrix`：把相机平移到原点，默认相机在 `(0, 0, 5)`。
- `get_projection_matrix`：先把透视视锥压成正交盒子，再平移、缩放到 `[-1, 1]`。默认视场角 45°，近平面 0.1，远平面 50，宽高比 1。
- `rasterizer`：模型、视图、投影矩阵相乘后做视口变换，三角形三条边用 Bresenham 画到 700×700 的帧缓冲。

三角形顶点固定。程序启动时默认已经旋转 180°。

## 运行

依赖 Eigen 和 OpenCV，需要自行配置包含目录和库目录。用 Visual Studio 打开 `202330450581+黄锦中+HW1/CGHW1.sln` 编译。生成的程序名是 `HWd.exe`。

交互模式下：

- `A`：角度加 10°
- `D`：角度减 10°
- `Esc`：退出

也可以指定角度并直接出图：

```text
HWd.exe -r 90 output.png
```

命令行给出的角度会覆盖默认的 180°。
